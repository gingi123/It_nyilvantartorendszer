## Leírás
Ez a repository a vizsgaremek projekt backend és frontend részét egyben tartalmazza.  
A backend REST API-t biztosít a frontend számára, és MySQL adatbázissal kommunikál.

## Használt backend technológiák
- ASP.NET Core (.NET 8)
- MySQL Entity Framework Core
- Microsoft Entity Framework Core Tools
- MySQL / MariaDB
- REST API
- JSON alapú kommunikáció
